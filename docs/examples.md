# pumpfun-creator-rewards examples

Look up Pump.fun creator-fee earnings by coin mint, wallet, or username.

## Example 1

```bash
curl "https://pumpfun-creator-rewards-lp642k3kpa-uc.a.run.app/api/fees?q=<mint|wallet|username>"
```

## Example 2

```bash
npm install
npm run dev          # vite on :3000, all three /api routes served by middleware
```

## Example 3

```bash
npm run serve        # build, then node server.js on :8080
```

## Example 4

```bash
gcloud auth login              # once, if your token has expired
npm run deploy
```


Every snippet above is taken from the [repository documentation](https://github.com/nirholas/pumpfun-creator-rewards#readme).
